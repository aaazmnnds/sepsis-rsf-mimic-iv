SECTION 7: PYTHON CODE TO GENERATE TABLES
================================================================================

Here's code to create Table 1 (Main Results):

```python
import pandas as pd

# Load summary
df = pd.read_csv('model_performance_summary.csv')

# Filter for real MIMIC data and test metrics
df_real = df[df['Mechanism'] == 'full']

# Create separate dataframes for each metric
cv = df_real[df_real['Metric'] == 'C-index (CV)'][['Imputation', 'Model', 'Formatted']].rename(columns={'Formatted': 'CV'})
test = df_real[df_real['Metric'] == 'C-index (Test)'][['Imputation', 'Model', 'Formatted']].rename(columns={'Formatted': 'Test'})
ibs = df_real[df_real['Metric'] == 'IBS (Test)'][['Imputation', 'Model', 'Formatted']].rename(columns={'Formatted': 'IBS'})

# Merge
result = cv.merge(test, on=['Imputation', 'Model'], how='left')
result = result.merge(ibs, on=['Imputation', 'Model'], how='left')

# Pivot to wide format
table1 = result.pivot(index='Imputation', columns='Model', values=['CV', 'Test', 'IBS'])

# Export to LaTeX
table1.to_latex('table1_main_results.tex', escape=False)
print(table1)
```
